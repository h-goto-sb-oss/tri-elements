# TRI-ELEMENTS ／ 三属の戦記

炎・水・草の3属性で戦う、一人用RPG進行のコレクション型カードゲーム。
ブラウザだけで動きます（ビルド不要・保存はlocalStorage）。

```bash
npm install
npm run dev        # http://localhost:5180
```

## 構成

```
src/engine/     ルールとカードの本体（ブラウザ・Node 両対応の純粋ロジック）
  cards.js        第1弾55種
  cards_set2.js   第2弾『嵐の来訪者』35種（パック用）
  cards_set3.js   第3弾『星辰の門』34種（レジェンド4種を含む）
  rules.js        ルール定数（検証用フラグつき）
  game.js         状態遷移・戦闘処理・効果処理
  ai.js           1手先読みの貪欲AI（テストプレイの対戦相手も兼ねる）
src/game/       デッキ・キャンペーン・セーブ
src/ui/         画面描画とイラスト生成
sim/            ヘッドレスのテストプレイ（バランス検証）
tools/          スクリーンショット・カード一覧・イラスト切り出し
assets/art/     カードIDごとの差し替えイラスト
```

## テストプレイ（バランス検証）

```bash
node sim/stats.js --games 300      # テンポ・ダメージ内訳・防御モードの使用率
node sim/run.js --games 60         # デッキ総当たりと先攻/後攻
node sim/campaign.js --games 40    # キャンペーンの難易度カーブ
node sim/cardpower.js --games 100  # カード1枚ずつの実効パワー（1枚差し替え法）
node sim/profiles.js               # 攻撃型AI vs 守備型AI（守りが報われすぎていないか）
node sim/sweep.js                  # ルール案の比較
```

`--rules key=value,...` で `src/engine/rules.js` の値を上書きして比較できます。

## 素材の差し替え

| 置き場所 | 内容 |
|---|---|
| `assets/art/<カードID>.png` | カードのイラスト（512pxの透過PNG。背景は弾ごとに自動で敷かれます） |
| `assets/enemies/area-NN-MM-名前.png` | 敵の立ち絵（NN=エリア1〜8、MM=敵1〜3）。無い間は代表カードの絵 |
| `assets/backgrounds/area-NN-名前.png` | エリアの背景（冒険画面と戦闘画面の両方で使用） |
| `assets/backgrounds/battle-common.png` | 共通の戦闘背景（フリーバトルで使用） |
| `assets/players/avatar-N-名前.png` | プレイヤーのアバター6種（N=1〜6） |
| `assets/audio/bgm_menu.*` | タイトル / デッキ編集 / カード図鑑 / ルール説明 |
| `assets/audio/bgm_map.*` | 冒険（エリア画面） |
| `assets/audio/bgm_battle.*` | 戦闘画面 |
| `assets/audio/se_*.*` | 効果音（下表の21種） |

効果音は次の21種を読み込みます。置いたものだけが鳴り、無いものは無音のまま進行します。

| ファイル名 | 鳴るタイミング |
| --- | --- |
| `se_click` | ボタン・カードを選ぶ |
| `se_error` | 使えない操作 |
| `se_draw` | カードを引く |
| `se_summon` | モンスターを召喚 |
| `se_support` | サポートを使う |
| `se_equip` | 装備をつける |
| `se_attack` | モンスターへの攻撃 |
| `se_direct` | 直接攻撃 |
| `se_hit` | ライフにダメージ |
| `se_destroy` | モンスターが破壊される |
| `se_heal` | ライフ回復 |
| `se_buff` | モンスターの強化 |
| `se_mode` | 攻撃／防御モードの切り替え |
| `se_forge` | 鍛錬 |
| `se_turn` | ターン開始 |
| `se_battle` | バトル開始 |
| `se_pack` | パックを開ける |
| `se_reveal` | カードがめくれる |
| `se_rare` | レア以上が出た |
| `se_win` | 勝利 |
| `se_lose` | 敗北 |

音声の拡張子は `.mp3 / .ogg / .m4a / .wav` のどれでも構いません。
アプリの「サウンド設定」画面で読み込み状況を確認できます。

敵と背景を追加・差し替えたら `python tools/make_manifest.py` を実行してください
（`src/ui/assets_map.js` を作り直します）。

イラストの一括取り込みは `python tools/import_art.py`（OneDriveの素材フォルダから
名前でカードに割り当て、透明な余白を自動でトリムします）。

## 配信用の画像（公開するとき必須）

`assets/` は差し替え用の**原本**（PNG・高解像度）で、Vite はここを `dist/` へコピーしません。
公開する前に次を実行して、`public/assets/` に配信用の WebP を作ってください。

```
python tools/optimize_assets.py
```

- 原本は一切書き換えません。`public/assets/` を作り直すだけです
- `src/ui/art_map.js` と `src/ui/assets_map.js` の参照先も webp に差し替えます
- 素材を差し替えたら、`make_manifest.py` / `adopt_art.py` のあとにこれを流してください
- `--dry` で削減量だけ確認、`--force` で全部作り直し

解像度の上限は「画面で実際に使う最大サイズ×2」に合わせてあります
（カードのイラストは図鑑の拡大表示で等倍近く使うので縮小していません）。
実測で 129MB → 15MB になります。

カード一覧（名前の重複チェック用のHTML）は次の2手順で作れます。

```
node tools/dump_cards.mjs > cards_export.json
python tools/make_cardlist.py cardlist.html
```

効果が重なっているカードの洗い出しは次のコマンドです。

```
node tools/scan_overlap.mjs
```

カード名や説明文ではなく `effects` / `onSummon` のデータそのものを突き合わせるので、
言い回しが違っても「ほぼ同じ札」を取りこぼしません。効かせる相手の属性しばりが違うもの
（炎デッキ用と水デッキ用など）や、付与するキーワードが違うものは別物として扱います。
カードを足したり数値をいじったら、これを流して 0 件になることを確認してください。

`assets/art/` へ直接ファイルを置いた場合は `python tools/adopt_art.py` を実行してください。
「カード名.png」を `<カードID>.png` へ改名し、余白をトリムして `src/ui/art_map.js` を作り直します
（`--dry` で対応表だけ確認できます）。ファイル名は必ずカードIDかカード名にしてください。

## レア度

コモン ＜ アンコモン ＜ レア ＜ エピック ＜ レジェンド。
第1弾はレアまで、第2弾はエピックまで、第3弾でレジェンドが登場します。
枠の光り方が変わり、パックの排出率も変わります。

## 現在の数値（AI同士 880戦）

| 指標 | 値 | 備考 |
|---|---|---|
| 平均決着ターン | 14.6 | 1戦およそ5〜8分 |
| 先攻勝率 | 50.5% | 後攻に手札+1枚と初手コスト+1 |
| デッキ切れ決着 | 10.2% | 山札削りデッキの勝ち筋として機能 |
| 手札上限で捨てた枚数 | 1.2枚/試合 | 上限5枚のときは7.1枚が無駄になっていた |
| 防御モードでの召喚 | 31% | モード選択が実際に使われている |

## 原案から変更したルール

| 項目 | 原案 | 現在 | 理由 |
|---|---|---|---|
| 召喚回数 | 1ターン1体 | **コストが続く限り何体でも** |
| 余ったコスト | 使い道なし | **【鍛錬】2コストで1ドロー（1ターン1回）** |
| 場が満杯のとき | 召喚できない | **【入れ替え召喚】自分の1体を墓地へ送って召喚（コスト+1）** |
| 装備サポート | 制限なし | **1体につき1枚まで** |
| 属性サポート | 制限なし | **同じ属性の自分のモンスターにしか使えない** |
| 手札上限 | 5枚 | 6枚 | 上限5だと1試合あたり7.1枚が捨て札になり、ドロー効果が機能しなかった |
| 防御モードの突破 | 超過ダメージなし | **超過分の半分がプレイヤーへ** | 完全カットだと守って山札切れを狙うのが最適解になり平均26.7ターン・デッキ切れ39%。全額だと防御にする意味が薄い。半減なら勝率を変えずに防御モードの使用率だけ 26.5%→29.0% に上がった |
| 攻撃モード同士 | 勝者側の超過のみ明記 | 負けた側も差分を受ける | 無謀な攻撃にリスクを与えるため |
| モード変更 | タイミング自由・1ターン1回 | ＋攻撃済みは変更不可 | 攻撃後に防御へ逃げられると防御モードのデメリットが消える |
| 属性相性 | 未定義 | 有利属性は戦闘時 攻撃力+2 | 炎→草→水→炎 |
| 最大コスト | 上限なし | 10で打ち止め | |
| 先攻/後攻 | 先攻はドローなし | ＋後攻は手札+1枚・初手コスト+1 | 先攻勝率60%→50% |
| 【貫通】 | 防御貫通ダメージ | **【守護】を無視して攻撃対象を選べる** | 防御貫通が標準になったため役割を変更 |
| マリガン | なし | 1回引き直し可 | 1コスト帯が引けない事故を防ぐ |
| ターン上限 | なし | 60ターン | 引き分け防止の安全弁 |

## 追加したキーワード

- 【守護】相手はまずこのモンスターを攻撃対象に選ぶ
- 【貫通】【守護】を無視して攻撃対象を選べる
- 【連撃】1ターンに2回攻撃できる（第2弾）
- 【加速】召喚したとき自分の最大コストを1増やす（第3弾）
- 【観測】登場時、山札の上から3枚を見て1枚を手札に加える（第3弾）

## イラストの差し替え

`assets/art/<カードID>.png` を置くと自動で反映されます（`src/ui/art_map.js` に登録）。
無い場合は手続き生成のSVGが使われます。カードIDは `node tools/sheets.js` が出力する
属性別一覧（`shots/cards_*.png`）の各カード右下に書かれています。

参考シート画像からの切り出しは `python tools/slice_art.py sheet1 --debug` →
`python tools/map_art.py` の順で実行します。
