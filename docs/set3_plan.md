# 第3弾『星辰の門』／新エリア／プレイヤーアバター 一覧

## 0. テイストの方針

| 弾 | モチーフ |
|---|---|
| 第1弾 | 生き物（動物・精霊・竜） |
| 第2弾『嵐の来訪者』 | 荒ぶる生き物（嵐・稲光をまとった獣） |
| **第3弾『星辰の門』** | **生き物ではないもの** — 星の力を宿した無機物・現象 |

第3弾は動物を出しません。**結晶・光・機械仕掛け・天体・彫像・門・鏡・環**が主役です。
輪郭は幾何学的で、体の内側に星や宇宙が透けて見える、という統一イメージ。
色は各属性の色を保ったまま、**金の縁取りと星の粒**を共通のアクセントにすると弾がひと目で分かります。
